我日常编程开发所依靠的是一套技能， 而不是那种让模型替你把控一切的"vibe coding".

在构建应用程序的过程中，各种工作流总试图使用既定的流程来帮忙, 但是却剥夺了你对开发过程的控制, 进而导致流程中的bug难以定位和解决.

为此, 我提炼日常使用一组设计精简，且可以灵活搭配的技能, 力求与任何模型兼容. 

将这些技能融入你自己的开发流程中，你会体验到掌控代码的踏实与快乐.

如果你希望了解这些能力的更新， 欢迎订阅.

## 目录说明

### core
所有和代码、架构、技术栈相关的硬技能都放在这里.

### toolbox
开发工具与工作流、 配置、Linux 常用命令、指令、沟通协作、项目管理这些软技能和工具.

### archive
归档区. 不管是你不需要再看的，还是技术栈过时的，统统直接丢到这里.
永远保持 core 的整洁，只放正在进行或高频使用的.

### inbox
不知道放哪里的记录、临时想法，全部丢到这里. 
每周五用 5 分钟清空一次，归类到上面三个文件夹，或者直接删除.
